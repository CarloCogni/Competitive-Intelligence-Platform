Convergence Summary

Threshold = the % change that triggers an alert for this metric on each entity. Cold Start is the LLM estimate; Latest (ML) is the most recent Isolation Forest value.

Entity Cold Start Latest (ML) Δ Change Trend Points

Cold start — Month 1 threshold is an LLM-suggested estimate for new entities before any training data is available.

Dynamic — Subsequent months use an Isolation Forest model trained on historical metric snapshots. The threshold is the 95th-percentile absolute change (p95_abs_change) observed in the training window.

Convergence — As more data accumulates, the ML-derived threshold tightens toward the true signal variance, reducing false positives. A ↓ Tightening trend is the desired outcome.
