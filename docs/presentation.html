Blockstream operates across seven product verticals and competes with over 30 organisations. Today, tracking competitors means checking GitHub, news, and app stores manually — once a week, if at all.

The Problem

  • Competitor activity is scattered across GitHub, news, and app stores
  • Manual monitoring doesn't scale to 30+ entities across 7 verticals
  • Signals are noticed days late — or not at all
  • No shared view of what changed and why it matters

The Goal

  • Aggregate public signals automatically, on a schedule
  • Alert when a metric moves beyond a meaningful threshold
  • Surface new competitor candidates from news
  • Deliver a weekly intelligence briefing via AI

System Design

Three-Layer Architecture

One codebase · one process · one database. No microservices, no message broker.

Layer 1
Data Ingestion
  • GitHub API
  • Google News RSS
  • App Store API (iOS)
  • Google Play (scraper)
  • Twitter v2 API
  • Reddit public API
  • GitHub releases.atom
7 fetchers · each independently testable · failures never crash the scheduler
→
Layer 2
Storage & Detection
  • SQLite (zero-setup, production schema)
  • MetricSnapshot (raw JSON) + flat Metric rows
  • Delta detection — static & Isolation Forest
  • Compound rules via Genetic Algorithm
  • Competitor candidate extraction (LLM)
  • APScheduler — per-source configurable intervals
→
Layer 3
Dashboard
  • Entity overview (sortable table)
  • Vertical drill-down with breadcrumbs
  • Head-to-head comparison + radar charts
  • Unified feed (News / Releases / Alerts)
  • Alert feed with HTMX live polling
  • AI Observatory & weekly briefings

AI Intelligence Layer — beyond the assignment brief
Six AI systems that were not requested but were built anyway. They transform raw signals into actionable, self-improving intelligence.
Smart Anomaly Detection
Learns each entity's normal metric behaviour and alerts only on statistically unusual changes — not arbitrary fixed thresholds.
Isolation Forest · scikit-learn
Compound Alert Rules
Discovers multi-metric patterns that correlate with meaningful competitive events by evolving rules from user dismissal feedback.
Genetic Algorithm · F-beta fitness
Competitor Detection
Scans every news article for untracked entity mentions. LLM determines if a name is a genuine competitor. Fires alert after 3 mentions.
LLM structured output · Ollama / Groq
News Intelligence
Classifies every article by sentiment and strategic signal type. Generates summaries and key quotes. Plotly heatmap reveals media coverage patterns across entities and weeks.
LLM enrichment · Ollama-only · Plotly.js
Weekly Intelligence Briefings
Generates a narrative summary of the week's most important competitive signals — on-demand or on a schedule, with email delivery.
Ollama (local) · Groq cloud fallback
Momentum Tracking
Aggregates all metric velocities into a single speed score per entity. Tracks acceleration to spot rising stars and fading leaders.
Z-score normalization · quadrant analysis

Roadmap

Next Steps

Three highest-ROI improvements, ordered by impact vs. effort.

1
Market Metrics (CoinGecko + Mempool)
Add Bitcoin price, market cap, and network hash rate alongside competitive metrics. Both APIs are free with no keys required. Wires directly into the existing fetcher and delta pipeline — no architectural changes needed.
↑ Strategically relevant for Blockstream · Low effort (~2 days)
2
Cross-Source Alert Corroboration
Group alerts that fire within 48 hours across multiple sources for the same entity into a single "corroborated signal." Reduces noise, increases confidence. No new data needed — purely a post-processing layer on existing alerts.
↑ Highest noise-reduction value · Medium effort (~3 days)
3
AI-Enhanced Momentum
The momentum system currently uses pure statistics (z-scores). Three AI enhancements are ready to build: anomaly-aware weighting (Isolation Forest scores amplify unusual signals), GA-learned metric weights (evolve optimal weights from user engagement), and LLM trajectory narratives ("Green Wallet is accelerating due to a coordinated product push"). Each plugs into existing infrastructure.
↑ Transforms numbers into strategic intelligence · Medium effort (~3-5 days)
